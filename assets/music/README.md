# Background music (optional)

Drop royalty-free `.mp3` / `.m4a` / `.wav` tracks you are licensed to use in
this folder. The renderer picks one at random per video and mixes it quietly
under the voiceover (or at normal level on quote cards). With no tracks here,
videos still carry a silent audio stream.

Instagram's in-app music library is not available through the API, so music
has to be baked into the file — only use tracks you have the rights to.
